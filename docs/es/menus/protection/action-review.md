**Ruta:** [/preview](https://kineguard.com/preview) · **Tipo:** página

## 1. Propósito

Revisa intención, consecuencia, riesgo y decisión antes de una acción irreversible.

## 2. Cómo lo usa el usuario

1. Entra en Action Review e identifica si se trata de playground o contexto de una wallet conectada.
2. Selecciona el escenario disponible; revisa destino, método, red y datos que el preview realmente conoce.
3. Ejecuta la evaluación informativa y lee ALLOW, WARN, BLOCK o REQUIRE_APPROVAL, junto con motivo y governors.
4. Sigue cualquier Decision ID, Receipt ID y evidencia a History. Si dice No decision yet, no inventes ejecución.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Protección y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

El preview no solicita firma, no hace broadcast y no demuestra que el proveedor o la cadena ejecutaron una acción.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
