# Protección / Wallet Posture

[ES](../../../../docs/es/menus/protection/wallet-posture.md) · [EN](../../../../docs/en/menus/protection/wallet-posture.md) · [Index](../../index.md)

**Ruta:** [/wallet-health](https://kineguard.com/wallet-health) · **Tipo:** página

## 1. Propósito

Muestra el contexto de salud y riesgo que KINE puede observar de la wallet y de su sesión actual.

## 2. Cómo lo usa el usuario

1. Abre Wallet Posture después de Connect; si no hay sesión, la ausencia de lectura no significa riesgo cero.
2. Comprueba dirección, cadena, proveedor y fuentes de observación antes de interpretar el estado mostrado.
3. Distingue datos reales de sesión, perfiles demo, historial previo y señales sin datos disponibles.
4. Utiliza Approval Intelligence para examinar allowances y Action Review para comprender una acción futura.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Protección y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

OBSERVED no significa KINE GOVERNED. Un score saludable no demuestra que una EOA esté protegida de un drainer.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
