**Ruta:** [/approvals](https://kineguard.com/approvals) · **Tipo:** página

## 1. Propósito

Inspecciona allowances, spender, token y riesgos asociados en modo de solo lectura.

## 2. Cómo lo usa el usuario

1. Abre Approval Intelligence; elige el modo demo o una wallet compatible conectada para escaneo de lectura.
2. Si Approval evidence not available aparece, no interpretes cero como ausencia demostrada de approvals.
3. Revisa token, spender, allowance, alertas de permisos ilimitados y riesgo de contrato cuando exista evidencia.
4. Abre Advanced approval intelligence para historial y export JSON/CSV cuando esté disponible. Sigue a Action Review o Guardian.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Protección y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

La página no revoca automáticamente, no firma, no envía transacciones y no mueve fondos.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
