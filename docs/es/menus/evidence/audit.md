## 1. Propósito

Estado de disponibilidad del archivo de auditoría hospedado.

## 2. Cómo lo usa el usuario

1. Abre Evidence > Audit; lee el mensaje de disponibilidad.
2. La página declara que el archivo inmutable hospedado no está disponible en esta beta.
3. Usa History, Structured Records y Sessions para registros realmente disponibles.
4. No presentes la página Audit como certificación de retención empresarial ni prueba legal.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Evidencia y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

No hay un archivo de auditoría hospedado e inmutable operativo en esa beta.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
