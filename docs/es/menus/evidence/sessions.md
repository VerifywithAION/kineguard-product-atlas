## 1. Propósito

Contexto de conexión, señales de red y actividad de sesión del navegador.

## 2. Cómo lo usa el usuario

1. Abre Sessions y revisa si existe wallet conectada.
2. Recorre KINE Session Timeline: conexión, normalización, postura, Action Review, History.
3. Lee KINE Runtime Event Bus y cuenta los eventos efectivamente registrados.
4. Distingue observaciones de Future signal y Future evidence, como detección de anomalías.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Evidencia y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

Una sesión observada no garantiza seguridad ni crea por sí sola un recibo duradero.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
