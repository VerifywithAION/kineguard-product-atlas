## 1. Propósito

Identifica agentes y su origen sin convertirlos en firmantes de activos.

## 2. Cómo lo usa el usuario

1. Abre Agents > Identity, ancla de Agent Arena, no una página nueva.
2. Examina nombre, identificador, wallet asociada, fuente y condición demo, proposal-only o conectada.
3. Usa solo controles de conexión soportados, sin conceder firma de wallet ni introducir secretos.
4. Sigue a Permissions para verificar autoridad real, no solo identidad declarada.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Agentes y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

Registrar un agente o aportar BYOK no concede autoridad para gastar.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
