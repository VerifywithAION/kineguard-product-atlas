## 1. Propósito

Explica resultado y razón de una evaluación de agente.

## 2. Cómo lo usa el usuario

1. Abre Decisions y distingue una decisión de demo de una decisión generada en sesión.
2. Lee BLOCK/ALLOW/WARN, governors de identidad, policy, riesgo, budget y evidencia.
3. Revisa reason code, action ID y siguiente paso; ausencia de receipt significa prueba insuficiente.
4. Consulta History y separa decisión de llamada LLM, ejecución en wallet y resultado final.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Agentes y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

Bloquear una llamada de inferencia no es vetar una transacción de blockchain.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
