**Ruta:** [/receipts#history](https://kineguard.com/receipts#history) · **Tipo:** sección interna

## 1. Propósito

Historial de Evidence al que remite Agents; no es una aplicación separada de agente.

## 2. Cómo lo usa el usuario

1. Abre Agents > History y confirma que el destino es /receipts#history.
2. Filtra o inspecciona eventos del agente y su relación con wallet y sesión cuando existan.
3. Revisa el tipo de evento, verdict, ID y evidence references antes de deducir resultado.
4. Si hay solo sessionStorage u observaciones, indica que es historial de sesión limitado.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Agentes y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

No atribuyas receipts de otra cuenta ni confundas historial local con historial on-chain completo.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
