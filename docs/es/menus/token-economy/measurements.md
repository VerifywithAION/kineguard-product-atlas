**Ruta:** [/token-economy#measurements](https://kineguard.com/token-economy#measurements) · **Tipo:** sección interna

## 1. Propósito

Distingue conteos de caracteres, estimaciones de tokens y uso observado del proveedor.

## 2. Cómo lo usa el usuario

1. Abre Measurements y localiza original/reduced, baseline y métricas de uso.
2. Identifica si cada cifra es LOCAL DEMO, ESTIMATED o MEASURED.
3. Compara contexto, hashes, versión de policy y alcance del ensayo antes de reportar un porcentaje.
4. Consulta ledger/receipt si existe y protege datos privados antes de compartir.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Economía de tokens y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

Token Economy no es Economic Exposure: una mide inferencia y la otra autoridad sobre activos.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
