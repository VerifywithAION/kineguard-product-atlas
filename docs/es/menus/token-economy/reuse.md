# Economía de tokens / Reuse

[ES](../../../../docs/es/menus/token-economy/reuse.md) · [EN](../../../../docs/en/menus/token-economy/reuse.md) · [Index](../../index.md)

**Ruta:** [/token-economy#reuse](https://kineguard.com/token-economy#reuse) · **Tipo:** sección interna

## 1. Propósito

Explica reutilización de contexto validado y eliminación de duplicación.

## 2. Cómo lo usa el usuario

1. Abre Reuse y compara contexto original con contexto reducido.
2. Revisa los fragmentos retenidos: tarea, policy, proveedor, modelo y presupuesto.
3. Contrasta hashes o referencias de contexto si existen, antes de afirmar una reducción segura.
4. Distingue tokens estimados evitados de tokens medidos por proveedor.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Economía de tokens y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

Menos caracteres o una demo de deduplicación no prueban ahorro medido ni reutilización distribuida.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
