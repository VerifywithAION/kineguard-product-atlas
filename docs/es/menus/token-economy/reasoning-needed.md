## 1. Propósito

Separa tareas deterministas o reutilizables de llamadas externas de inferencia.

## 2. Cómo lo usa el usuario

1. Abre Reasoning Needed? dentro de Token Economy.
2. Revisa si hay respuesta determinista, contexto reusable o pasos redundantes.
3. Inspecciona budget, policy, identity y evidence gate antes de provider calls.
4. Comprueba el resultado BLOCKED_BEFORE_PROVIDER_CALL frente a uso medido del proveedor.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Economía de tokens y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

Una decisión de no llamar a un proveedor no significa ahorros facturados comprobados.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
