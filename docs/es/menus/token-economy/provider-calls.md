## 1. Propósito

Muestra decisiones anteriores al relay, claves BYOK efímeras y uso real del proveedor.

## 2. Cómo lo usa el usuario

1. Abre Provider Calls; identifica si se muestra LIVE RELAY, LOCAL DEMO o BLOCKED BEFORE PROVIDER CALL.
2. Para experimentos BYOK usa solo clave de proyecto dedicada y nunca la publiques en capturas.
3. Revisa proveedor/modelo, tarea, budget y decisión de governors antes del run permitido.
4. Compara resultado real y usage medido con estimaciones, sin equiparar tokens estimados a cobro real.

## 3. Qué mecanismo representa

La ruta pertenece a la familia Economía de tokens y debe relacionarse con identidad, política, request exacto y fuente de evidencia.

## 4. Evidencia y límites

El relay beta documentado es OpenAI por servidor; no demuestra firma de wallet ni compatibilidad con cualquier proveedor.

La visibilidad de una pantalla pública no equivale a aceptación humana de runtime ni a protección universal de fondos.
