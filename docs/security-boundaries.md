# Security and claim boundaries

This atlas is documentation, not an enforcement component. It contains no credentials, tokens, cookies, private keys, customer records, database exports, internal heuristics, or private application source.

## Never conflate

- A connected wallet with a protected wallet.
- A saved policy with an executed or blocked transaction.
- A provider decision with chain confirmation.
- Synthetic Chromium/PostgreSQL evidence with production protection.
- Historical Sepolia proof with universal EOA enforcement.
- A static control selector with an operational backend.

## Public claim rule

Every claim must identify its evidence class, scope, date, source, and limitations. Missing evidence is reported as unavailable or pending; it is never filled with demo telemetry.

## Privacy rule

Screenshots of authenticated Account, Wallet Details, or Admin surfaces are omitted unless explicitly captured from a sanitized synthetic account. Public pages must not expose customer identifiers or session material.
