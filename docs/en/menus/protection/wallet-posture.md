# Protection / Wallet Posture

[ES](../../../../docs/es/menus/protection/wallet-posture.md) · [EN](../../../../docs/en/menus/protection/wallet-posture.md) · [Index](../../index.md)

**Route:** [/wallet-health](https://kineguard.com/wallet-health) · **Kind:** standalone page

## 1. Purpose

Shows wallet health and risk context that KINE can observe from the current session.

## 2. How the user operates it

1. Open Wallet Posture after Connect; no session does not mean zero risk.
2. Check address, chain, provider and observation sources before interpreting any status.
3. Distinguish current session data, demo profiles, old history and unavailable signals.
4. Use Approval Intelligence for allowances and Action Review for a future action.

## 3. Underlying mechanism

This route belongs to the Protection family and must be interpreted with identity, policy, exact request and evidence provenance.

## 4. Evidence and limitations

OBSERVED is not KINE GOVERNED. A healthy score does not prove that an EOA is protected against a drainer.

A visible public screen does not equal human runtime acceptance or universal funds protection.
