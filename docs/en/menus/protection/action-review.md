# Protection / Action Review

[ES](../../../../docs/es/menus/protection/action-review.md) · [EN](../../../../docs/en/menus/protection/action-review.md) · [Index](../../index.md)

**Route:** [/preview](https://kineguard.com/preview) · **Kind:** standalone page

## 1. Purpose

Reviews intent, consequences, risk and decision before an irreversible action.

## 2. How the user operates it

1. Enter Action Review and identify whether it is a playground or connected-wallet context.
2. Choose an available scenario; review destination, method, chain and the data the preview actually knows.
3. Run informational evaluation and read ALLOW, WARN, BLOCK or REQUIRE_APPROVAL with reasons and governors.
4. Follow any Decision ID, Receipt ID and evidence to History. If it says No decision yet, do not invent execution.

## 3. Underlying mechanism

This route belongs to the Protection family and must be interpreted with identity, policy, exact request and evidence provenance.

## 4. Evidence and limitations

Preview does not request signing, broadcast transactions or prove that provider or chain executed an action.

A visible public screen does not equal human runtime acceptance or universal funds protection.
