## 1. Purpose

Shows pre-relay decisions, ephemeral BYOK credentials and actual provider use.

## 2. How the user operates it

1. Open Provider Calls; identify LIVE RELAY, LOCAL DEMO or BLOCKED BEFORE PROVIDER CALL.
2. For BYOK experiments use a dedicated project key and never publish it in screenshots.
3. Review provider/model, task, budget and governor verdict before an allowed run.
4. Compare actual result and measured usage with estimates; do not equate estimated tokens with billing.

## 3. Underlying mechanism

This route belongs to the Token Economy family and must be interpreted with identity, policy, exact request and evidence provenance.

## 4. Evidence and limitations

The documented beta relay is OpenAI server-side; it proves neither wallet signing nor every provider.

A visible public screen does not equal human runtime acceptance or universal funds protection.
