## 1. Purpose

Distinguishes character counts, token estimates and observed provider usage.

## 2. How the user operates it

1. Open Measurements and locate original/reduced, baseline and usage metrics.
2. Identify whether each number is LOCAL DEMO, ESTIMATED or MEASURED.
3. Compare context, hashes, policy version and experiment scope before reporting percentages.
4. Consult ledger/receipt where present and redact private information before sharing.

## 3. Underlying mechanism

This route belongs to the Token Economy family and must be interpreted with identity, policy, exact request and evidence provenance.

## 4. Evidence and limitations

Token Economy is not Economic Exposure: one measures inference and the other asset authority.

A visible public screen does not equal human runtime acceptance or universal funds protection.
