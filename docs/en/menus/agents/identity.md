## 1. Purpose

Identifies agents and provenance without turning them into asset signers.

## 2. How the user operates it

1. Open Agents > Identity, an anchor within Agent Arena, not a separate page.
2. Inspect name, identifier, related wallet, source and demo, proposal-only or connected state.
3. Use only supported connection controls, without granting wallet signing or entering secrets.
4. Continue to Permissions for effective authority, not just a declared identity.

## 3. Underlying mechanism

This route belongs to the Agents family and must be interpreted with identity, policy, exact request and evidence provenance.

## 4. Evidence and limitations

Registering an agent or supplying BYOK does not confer spending authority.

A visible public screen does not equal human runtime acceptance or universal funds protection.
