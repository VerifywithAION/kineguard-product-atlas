## 1. Purpose

Explains the result and reason of an agent evaluation.

## 2. How the user operates it

1. Open Decisions and distinguish demo decisions from session-generated decisions.
2. Read BLOCK/ALLOW/WARN and identity, policy, risk, budget and evidence governors.
3. Review reason code, action ID and next step; no receipt means insufficient evidence.
4. Consult History and separate decision, LLM provider call, wallet execution and finality.

## 3. Underlying mechanism

This route belongs to the Agents family and must be interpreted with identity, policy, exact request and evidence provenance.

## 4. Evidence and limitations

Blocking an inference call is not vetoing a blockchain transaction.

A visible public screen does not equal human runtime acceptance or universal funds protection.
