## 1. Purpose

Evidence history targeted by Agents; not a separate agent application.

## 2. How the user operates it

1. Open Agents > History and confirm the target is /receipts#history.
2. Filter or inspect agent events and their wallet/session relationship when available.
3. Review event type, verdict, IDs and evidence references before inferring outcome.
4. If only sessionStorage or observations exist, state that this is limited session history.

## 3. Underlying mechanism

This route belongs to the Agents family and must be interpreted with identity, policy, exact request and evidence provenance.

## 4. Evidence and limitations

Do not reassign another account's receipts or confuse local history with complete on-chain history.

A visible public screen does not equal human runtime acceptance or universal funds protection.
