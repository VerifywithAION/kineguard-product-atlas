# Public release manifest — provenance and exclusions

**Scope:** publish the public-safe, evidence-bounded technical Atlas as native GitHub Markdown and embedded original images. The original Next.js SaaS, wallet extension, servers, smart contracts, test fixtures, customer records and credentials are **not** included.

## Included

- Authored README with inline images and bilingual navigation.
- Architecture, evidence ledger, seven detailed technical deep dives, nine consumer-mechanism pages, product/Guardian/AI descriptions.
- Original authentic brand PNG plus a cropped derivative preserving original pixels.
- Genuine user-uploaded static Atlas screenshots with immutable SHA-256 record.
- Nine owner-provided local-controlled product screenshots with public-safe redactions and a separate private intake backup.
- `AGENTS.md`, `llms.txt`, and `docs/capability-catalog.json` for researcher and agent-readable navigation.
- Editable conceptual SVG diagrams, clearly distinguished from screenshots or execution traces.
- Original R2/R3 public static preview under `demo/` solely as historical screenshot context. **Readers are not required to execute it or use any local website**.

## Explicitly excluded

- Previous failing local Chrome/CDP runners and OS-capture utilities; they are unnecessary for readers.
- An old backup PNG; duplicate screenshot presented as a normal feature page.
- Secrets, environment variables, customer data, private implementation APIs and code, telemetry, signing credentials, production database and testnet funds.

## Publication class

`PUBLIC DOCUMENTATION / EXPLICIT EVIDENCE BOUNDARIES`. No claim of general EOA protection, production-ready nine mechanisms, customer beta certification, on-chain audit, universal wallet veto or mainnet guarantee.

Subsequent documentation updates are tracked by Git commit and tree identity. The original SHA-256 manifest is a historical publication snapshot, not a current-tree attestation. No binary screenshot re-verification is asserted by the November 25 reconciliation.
